NETWORK FORENSICS / TFTP

TFTP: The Last Block

A router backup left a short packet capture behind. Find the useful TFTP transfer, follow its notes, and recover the protected file.

Evidence

The capture contains several TFTP transfers, including decoys. In Wireshark, use the tftp display filter and choose File → Export Objects → TFTP. You can also export with TShark:

tshark -r capture.pcap --export-objects tftp,out_dir
Download capture.pcap

The capture and correct flag are identical for every team. Your browser saves only your progress through the steps.

01

Identify the payload

Find the exported file that contains the protected payload.

Hint

One of the transferred text files names the encrypted payload. Work through the note chain.

02

Recover the key

Locked until you identify the payload.

Hint
